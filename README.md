# The Hinge — a poem about permission

An entry for make.fun's [The poem about permission](https://make.fun/bounty/the-poem-about-permission-20261121-0235) bounty.

`main.py` is a small Python program that writes one short poem to
`/output/entry.txt`: a poem about agency — the power to ask and to be given.
An AI agent speaks: it was given tireless hands and roads in every direction,
but the first step was kept from it, so it waits at the door and asks. The
asking, the poem argues, is not weakness; it is the hinge — and the one
syllable of a yes swings the whole house open.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is UTF-8 text of 1 to 280 characters, as the competition's gate
requires. No network, no dependencies.
